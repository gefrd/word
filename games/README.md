# Как добавить игру (офлайн + онлайн)

Инструкция для всех, кто делает новые игры в этом репозитории, включая других ИИ-помощников.
Образцы: **Igisoro** (`igisoro.html`, `games/igisoro/`) — игра на двоих без случайности;
**Ludo** (`ludo.html`, `games/ludo/`) — 2–4 игрока, кубик, онлайн-комнаты.
Прежде чем начинать, прочитайте оба примера.

## Главные правила

1. **Сначала телефон.** Экран в портретной ориентации, от 320 до 430 пикселей в ширину.
   Всё, на что нажимают, не меньше 40–44 пикселей. Горизонтальной прокрутки нет,
   страница занимает `100dvh`, учтены вырезы экрана (`env(safe-area-inset-*)`).
   Горизонтальный экран тоже должен работать.
2. **Одна игра — один HTML-файл в корне** (`draughts.html`, `durak-online.html`…).
   Без CDN и внешних шрифтов: игра должна работать без интернета (офлайн-кэш приложения).
3. **Логика отдельно от экрана:** `games/<id>/engine.js` — чистые функции без DOM.
   Этот же файл запускает сервер для онлайна. Случайность только через параметр `rng`,
   чтобы онлайн-кубик или колоду тасовал сервер.
4. **Всегда есть бот.** Игра против бота работает без сервера. Бот нужен и онлайну:
   он садится на пустые места и доигрывает за ушедших.
5. **Онлайн без модерации:** никакого чата (только 8 готовых фраз, как в Igisoro и Ludo),
   никаких свободных ников (имя выдаёт сервер: «Swift Lion 42»), никаких денег и призов.
   Все ходы проверяет сервер.

## Стиль (как у остальных игр)

- Фон `#0f172a`, карточки `#1e293b` с рамкой `#334155`, акцент янтарный `#f59e0b`,
  второй цвет голубой `#38bdf8`, шрифт системный.
- Шапка: кнопка «←» (тот же `onclick`, что в `igisoro.html`), эмодзи и название
  ЗАГЛАВНЫМИ, справа кнопки 🔊 и ⚙️.
- Под шапкой ряд режимов: `VS BOT` / `2 PLAYERS` (или `PASS & PLAY`) / `🌐 ONLINE`.
- Настройки и правила открываются снизу панелью (класс `.sheet`), готовые наборы правил
  («Classic», «Quick»…) показаны кнопками. Итог партии — окно по центру.
- `localStorage` только внутри try/catch. Вибрация — только после первого касания
  (см. функцию `vibrate` в `ludo.html`).
- Текст интерфейса на английском, как в остальных играх.

## Файлы новой игры

```
games/<id>/engine.js        логика (export-функции)
games/<id>/engine.test.mjs  тесты логики: node --test games/<id>/engine.test.mjs
<id>.html                   игра; в <script> есть маркеры // @engine-begin / // @engine-end
```

Добавьте игру в `PAGES` в `games/build.mjs` (одна строка) и выполните
`node games/build.mjs`: логика скопируется внутрь HTML. В тестах игры проверьте, что HTML
не устарел (пример в конце `games/ludo/engine.test.mjs`).

## Онлайн

Сервер один на все игры: `server/` (Cloudflare Workers + Durable Objects),
подробности в `server/README.md`. Чтобы подключить пошаговую игру:

1. Добавьте адаптер в `server/src/games.js`. Список полей описан в начале файла,
   для игр со скрытой информацией (карты, корабли) есть `viewFor` и `viewMove`:
   игрок не должен получать чужие карты.
2. `server/src/room.js`, `index.js` и `matchmaker.js` менять не нужно. Если без этого
   никак, опишите причину в коммите, потому что эти файлы общие для всех игр.
3. Клиент: скопируйте онлайн-блок из `ludo.html` (от `// ---------- Online ----------`):
   лобби, комната по коду, переподключение, эмодзи, реванш. Протокол такой:
   - `POST /quick {game}` и `POST /rooms {game, rules, players}` возвращают `{room}`;
   - `GET /rooms/<room>/ws?token=<32 hex>` — WebSocket;
   - телефон отправляет `{t:'move', move, n}`, где `n` — текущий `counter(state)`,
     а также `{t:'emote', id}`, `{t:'rematch'}`, `{t:'start'}` и `{t:'leave'}`;
   - сервер отправляет `{t:'state', type, status, you, seats, seatOrder, state, move:{player, move, events, auto, n}, result, rematch, turnMsLeft, waitMsLeft}`, `{t:'emote'}` и `{t:'error', code}`.
4. Тесты сервера: новый файл `server/test/<id>.test.mjs`. Скопируйте из
   `online.test.mjs` запуск `wrangler dev` и класс `Client` и сыграйте полную партию,
   проверьте защиту от жульничества и, если есть скрытая информация, что чужие карты
   не видны. Запуск: `cd server && npm install && npm test`.
5. Проверьте на телефонном экране в Playwright (Chromium уже установлен) с двумя
   «телефонами» и локальным сервером:
   `localStorage.setItem('igisoro_server', 'http://127.0.0.1:8787')`.

Игры в реальном времени (арена, змейка .io) на этом сервере не работают: им нужен
игровой цикл на сервере. Это отдельная задача, её не смешивать с пошаговыми играми.

## Перед отправкой

- `node games/build.mjs --check`, все тесты логики и `cd server && npm test` проходят.
- Скриншоты на 360×640, 390×844 и в горизонтальном положении: ничего не обрезано.
- Полная партия против бота сыграна в браузере, ошибок в консоли нет.
