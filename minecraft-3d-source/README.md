# minecraft-3d: мобильная версия

`minecraft-3d/` — сборка [Vyse12138/minecraft-threejs](https://github.com/Vyse12138/minecraft-threejs)
(MIT) с доработками для телефонов. Исходные изменения лежат в `mobile.patch`
относительно коммита `4d84cf5` оригинала.

## Что добавлено

Управление на телефоне:
- аналоговый джойстик слева (мёртвая зона, плавная скорость);
- обзор перетаскиванием пальца по свободной части экрана, можно одновременно
  с джойстиком (мультитач);
- тап по экрану ставит блок, удержание ломает (как в Bedrock);
- кнопки справа: прыжок, сломать, поставить (с иконкой выбранного блока),
  FLY / WALK, спуск в полёте; при удержании кнопки действие повторяется;
- хотбар с 7 блоками, выбор тапом; снизу в портретной ориентации, сверху
  в альбомной;
- кнопка паузы (меню, сохранение), автопауза при сворачивании;
  полноэкранный режим при старте;
- меню, настройки и подсказка помещаются на экран шириной 360px и на низкий
  экран в альбомной ориентации; учитываются вырезы экрана (safe-area).

Облегчённая графика (Настройки → Graphics):
- **Fast** — по умолчанию на слабых телефонах (≤4 ядер или ≤3 ГБ ОЗУ):
  рендер в 0.75 разрешения, дальность 1, Lambert вместо PBR, листва через
  alpha-test, без облаков, подсветка блока раз в 3 кадра;
- **Balanced** — по умолчанию на остальных телефонах: разрешение 1×,
  дальность 2, Lambert;
- **Fancy** — как в оригинале (по умолчанию на ПК).

Общее для всех режимов:
- адаптивное разрешение: при FPS < 28 картинка становится мягче, при FPS > 52
  резкость возвращается;
- ограничение 60 FPS на 90/120 Гц экранах;
- рисуются только заполненные экземпляры блоков (в оригинале GPU каждый кадр
  обрабатывал весь зарезервированный буфер, около 83 тыс. кубов);
- без выделения памяти на каждый кадр в подсветке блока;
- шаг физики ограничен, чтобы на тормозящем телефоне не провалиться сквозь
  землю;
- в портретной ориентации расширен угол обзора.

ПК-управление (клавиатура и мышь) не изменилось.

## Пересборка

```sh
git clone https://github.com/Vyse12138/minecraft-threejs.git
cd minecraft-threejs
git checkout 4d84cf5
git apply ../minecraft-3d-source/mobile.patch
npm install
npx vite build --base ./ --sourcemap false
# содержимое dist/ -> minecraft-3d/
```
