# Онлайн-сервер для игр (Cloudflare)

Один сервер для онлайн-режима всех игр: сейчас **Igisoro** и **Ludo**.
Работает на Cloudflare Workers + Durable Objects:
своего сервера нет, падать нечему. Каждая игровая комната — отдельный маленький объект
на серверах Cloudflare.

## Как это устроено

- **Все ходы проверяет сервер.** Телефон отправляет только «нажал лунку №5» или
  «брось кубик». Сервер проверяет ход тем же кодом, что и офлайн-игра
  (`games/*/engine.js`), и рассылает результат всем игрокам. **Кубик в Людо бросает
  сервер**, поэтому подделать шестёрку, ход или победу нельзя.
- **Нет чата и нет ввода ников.** Имя собирается автоматически («Swift Lion 42»),
  а из сообщений есть только 8 готовых фраз и эмодзи. Модерировать нечего.
- **Быстрая игра.** Сервер собирает игроков 15 секунд (в Людо до 4 человек), а
  пустые места занимают боты. Боты честно подписаны «Bot».
- **Комната по коду.** Игрок создаёт комнату, получает код из 4 цифр
  (например, 4821) и отправляет его друзьям. В Людо хозяин комнаты может нажать
  «Start now», и пустые места займут боты.
- **Кто не ходит вовремя** (Igisoro — 45 секунд, Людо — 20 секунд), за того ход
  делается автоматически. В игре на двоих после двух пропусков игрок проигрывает.
  В Людо на 3–4 игроков за ушедшего игрока доигрывает бот, а если игрок вернётся,
  он снова получает своё место.
- **Если телефон потерял связь,** он сам переподключается и возвращается на своё место.
- **Пустые комнаты удаляются сами.**

## Как опубликовать (один раз, минут 10)

1. Зарегистрируйтесь на https://dash.cloudflare.com (бесплатно).
2. Установите Node.js 20 или новее: https://nodejs.org
3. В терминале, в папке `server`:
   ```
   npm install
   npx wrangler login      # откроется браузер: войдите в Cloudflare
   npx wrangler deploy
   ```
   В конце будет адрес вида `https://kivu-games.ВАШЕ-ИМЯ.workers.dev`.
4. Проверьте его в браузере: `https://kivu-games.ВАШЕ-ИМЯ.workers.dev/health`
   должен показать `{"ok":true}`.
5. Откройте `igisoro.html` и `ludo.html` и в каждом впишите этот адрес в строку
   ```js
   const ONLINE_SERVER = '';
   ```
   например так: `const ONLINE_SERVER = 'https://kivu-games.ВАШЕ-ИМЯ.workers.dev';`
6. (Желательно) В `wrangler.toml` впишите адрес вашего сайта, чтобы чужие сайты
   не могли пользоваться сервером, и снова выполните `npx wrangler deploy`:
   ```toml
   ALLOWED_ORIGINS = "https://ваш-сайт.rw"
   ```

Пока адрес не вписан, кнопка 🌐 ONLINE в игре показывает «Online play is not set up yet»,
а режимы «против бота» и «2 игрока» работают как обычно.

## Сколько стоит

На старте — бесплатно: на бесплатном плане Workers есть дневные лимиты на запросы и
Durable Objects, и небольшой аудитории их хватает. Если игроков станет много, нужен
план Workers Paid ($5 в месяц). Актуальные лимиты: https://developers.cloudflare.com/durable-objects/platform/pricing/

Трафик маленький: один ход — это несколько сотен байт, вся партия — десятки килобайт.

## Проверка на своём компьютере

```
npm install
npm test          # поднимает сервер локально и играет партии через WebSocket
npm run dev       # локальный сервер на http://localhost:8787
```

Чтобы открыть игру с локальным сервером, в консоли браузера на странице игры выполните
`localStorage.setItem('igisoro_server', 'http://localhost:8787')` и перезагрузите страницу.

## Файлы

- `src/index.js` — адреса сервера: создать комнату, быстрая игра, подключение.
- `src/games.js` — подключённые игры (Igisoro, Ludo). Новая пошаговая игра
  добавляется сюда: её `engine.js` и несколько строк адаптера.
- `src/room.js` — игровая комната: ходы, таймеры, боты, реванш, переподключение.
- `src/matchmaker.js` — подбор соперника для быстрой игры.
- `src/names.js` — автоматические имена.
- `test/online.test.mjs` — проверки обеих игр: полная партия, защита от жульничества,
  переподключение, быстрая игра, боты, тайм-аут, эмодзи, сдача.

После правки `games/*/engine.js` выполните `node games/build.mjs` в корне репозитория:
он копирует правила внутрь `igisoro.html` и `ludo.html`, чтобы каждая игра оставалась
одним файлом.
